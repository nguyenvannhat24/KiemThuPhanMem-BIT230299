# TEST PLAN – E-COMMERCE WEBSITE

## 1. Introduction

Tài liệu mô tả kế hoạch kiểm thử thủ công cho hệ thống website bán hàng online.

## 2. Scope

### In-scope

- Authentication
- Product & Cart
- Checkout

### Out-of-scope

- Performance testing
- Automation testing

## 3. Test Approach

- Functional testing
- UI testing (basic)
- Smoke & Regression testing

## 4. Test Environment

- Browser: Google Chrome
- OS: Windows
- Test data: Tài khoản giả lập

## 5. Entry Criteria

- Chức năng hoàn thành
- Môi trường sẵn sàng

## 6. Exit Criteria

- ≥ 95% test case được thực thi
- Không còn bug Critical

## 7. Risks & Mitigation

- Rủi ro: Thiếu thời gian test
- Giảm thiểu: Ưu tiên test chức năng chính

## 8. Roles & Responsibilities

- Tester: Thiết kế test case, execute test
- QA Lead: Review & report

## 9. Test Schedule

- Test case design: 3 ngày
- Test execution: 4 ngày
- Reporting: 2 ngày
